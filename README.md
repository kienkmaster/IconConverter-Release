# IconConverter

## English

IconConverter is a Windows application for converting PNG images to ICO files and making several common PNG edits. Each tool has its own tab, and processed images are listed in the History panel.

### Tools

| Tool | What it does |
| --- | --- |
| **Icon Converter** | Creates a multi-size ICO file from one PNG image. The largest embedded size can be set to 64 × 64, 128 × 128, or 256 × 256 pixels. |
| **Color Converter** | Applies the selected RGB color to every visible pixel. Existing alpha values are kept, so translucent areas remain translucent. |
| **Crop or Expand** | Crops transparent margins from an image or adds space around its canvas. Cropping can keep a selected aspect ratio or fit tightly around visible content. |
| **Resize** | Resizes images by percentage or by pixel dimensions. The original aspect ratio can be kept or unlocked. |
| **Add Border** | Draws a colored border around visible content. Border color and thickness are adjustable. |
| **Set Transparency** | Makes an edge-connected background transparent or changes the opacity of the entire image. |

### Using the image tools

The Icon Converter tab works with one PNG file at a time. The other image tools accept multiple PNG files and can also receive PNG or bitmap data dragged from another application.

Before running a tool, choose its output folder and review the images in the list. Finished items can be removed without clearing the images that still need attention.

The History panel keeps recent results close at hand. From there, an image can be located in File Explorer or passed to another tool.

### Appearance

Four themes are available: System, Light Blue, Dark Blue, and Dark Gold. Color-related tools also include a screen color picker. Theme and application preferences are remembered for the next session.

## Tiếng Việt

IconConverter là ứng dụng Windows dùng để chuyển ảnh PNG sang file ICO và thực hiện một số thao tác chỉnh sửa PNG thường gặp. Mỗi công cụ nằm trong một tab riêng; ảnh đã xử lý được ghi lại ở bảng History.

### Các công cụ

| Công cụ | Chức năng |
| --- | --- |
| **Icon Converter** | Tạo file ICO đa kích thước từ một ảnh PNG. Kích thước lớn nhất trong file ICO có thể chọn là 64 × 64, 128 × 128 hoặc 256 × 256 pixel. |
| **Color Converter** | Đổi toàn bộ pixel nhìn thấy sang màu RGB đã chọn. Giá trị alpha ban đầu được giữ lại nên vùng bán trong suốt không bị mất. |
| **Crop or Expand** | Cắt phần lề trong suốt hoặc thêm khoảng trống quanh khung ảnh. Khi cắt, có thể giữ tỷ lệ đã chọn hoặc cắt sát nội dung nhìn thấy. |
| **Resize** | Đổi kích thước ảnh theo phần trăm hoặc số pixel. Có thể giữ nguyên tỷ lệ ảnh gốc hoặc thay đổi chiều ngang và chiều dọc độc lập. |
| **Add Border** | Vẽ đường viền màu quanh phần nội dung nhìn thấy. Người dùng có thể chọn màu và độ dày đường viền. |
| **Set Transparency** | Làm trong suốt phần nền nối với biên ảnh hoặc thay đổi độ mờ của toàn bộ ảnh. |

### Sử dụng các công cụ xử lý ảnh

Tab Icon Converter xử lý từng file PNG. Các công cụ còn lại nhận được nhiều file PNG cùng lúc, đồng thời hỗ trợ dữ liệu PNG hoặc bitmap được kéo từ ứng dụng khác.

Trước khi xử lý, người dùng chọn thư mục đầu ra và kiểm tra danh sách ảnh. Những mục đã hoàn thành có thể được xóa riêng, không ảnh hưởng đến các ảnh đang chờ xử lý.

Bảng History lưu các kết quả gần đây. Từ đây, người dùng có thể mở vị trí file trong File Explorer hoặc chuyển ảnh sang một công cụ khác.

### Giao diện

Ứng dụng có bốn giao diện: System, Light Blue, Dark Blue và Dark Gold. Các công cụ liên quan đến màu sắc có thêm chức năng lấy màu trực tiếp trên màn hình. Lựa chọn giao diện và thiết lập ứng dụng được lưu cho lần mở tiếp theo.
